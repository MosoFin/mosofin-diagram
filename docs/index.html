01 — What it is

A checked map of how the business runs.

A free, MIT-licensed agent skill for Cursor, Claude Code, Codex CLI, and OpenCode. It turns a short interview about your operating stack into one self-contained HTML diagram.

One source of truth per fact

Orders, cash and books each have exactly one owner in the map. Two systems claiming the same number is a brief failure, not a diagram.

No invented numbers

If you did not supply an amount, it does not appear. The renderer never calls QuickBooks, Stripe, Shopify, an ERP, or a bank.

06 — FAQ

What people ask before they install.

Is this the same product as mosofin.com?

No. MosoFin is a read-only financial data workspace in Claude. MosoFin-diagram is a free, open-source skill that draws a map of how the business runs. They share a name and a team — not data.

Does it invent numbers?

No. If you did not supply an amount, it does not appear. The skill never calls QuickBooks, Stripe, Shopify, an ERP, or a bank.

What do I get back?

One self-contained HTML file. Zero dependencies, no server, no runtime. Open it in any browser, forward it, or export PNG, JPEG, WebP, SVG, or WebM.

Which agents does it support?

Cursor, Claude Code, Codex CLI, and OpenCode via the switcher. Raven is a manual ZIP install: extract mosofin.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/mosofin.
