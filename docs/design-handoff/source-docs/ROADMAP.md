# Mosofin roadmap

The current development line is `v1.0.0-dev.0`; it contains the work under Changelog Unreleased and is not a stable release.

## v1.0 — finance-first foundation
- Finance brief onboarding as the default entry point.
- Eight finance recipes routed from plain-language intent.
- Sample Northline Coffee money map shipped in the repo.

## Next
- Period-over-period flux dataflow recipe with materiality thresholds.
- Multi-entity consolidation money map.
- Client-facing "explain this diagram" companion note per artifact.

## Standing boundaries
- Last-Good Live Preview is an optional local loop only: no server state, port, path, error, or reload token enters HTML or any export, and installed ZIP skills keep the zero-dependency contract.
- The renderer never reads a live ledger, processor, or bank; every amount is authored or user-stated.
