What is MosoFin-diagram?

A checked map of how the business runs.

MosoFin-diagram is a free, MIT-licensed agent skill. It turns a short interview about the operating stack into one self-contained HTML diagram. Every node names the system that owns the fact. The renderer never invents an amount, a volume, or a headcount.

One source of truth per fact

Orders, cash and books each have exactly one owner in the map. Two systems claiming the same number is a brief failure, not a diagram — Mosofin stops and asks you to pick.

No invented numbers

If you did not supply an amount, a volume or a headcount, it does not appear. The renderer never calls QuickBooks, Stripe, Shopify, an ERP or a bank, and never marks a reconciliation green without a zero difference.

How it works

Four steps from add to a diagram you can forward.

One checked Skill for Cursor, Claude Code, Codex, and OpenCode. Their switcher generates exact commands; for Raven, extract mosofin.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/mosofin.

Step 1

Add the skill

Run npx skills add MosoFin/mosofin-diagram -g, or open the Get started page for an exact Cursor, Codex, Claude Code, or OpenCode command. Raven is not a switcher target; for a manual ZIP install, extract mosofin.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/mosofin.

Step 2

Describe the business

A short interview: what the business does, which entities are in scope, and which system owns each domain — CRM, commerce, supply chain, payments, bank, books. It is saved as a brief so you only answer once.

Step 3

Ask one question

"Map how our business runs." "Why doesn't Shopify match QuickBooks?" "Can we make payroll on the 15th?" Mosofin picks the diagram type, checks it, and hands back one HTML file you can refine in chat.

Step 4

Share the map

Forward the HTML, export a share card, or walk a guided view. The file is self-contained — no account, no server, no invented numbers.

Questions, answered

What people ask before they install.

Is this the same product as mosofin.com?

No. MosoFin is a read-only financial data workspace in Claude. MosoFin-diagram is a free, open-source skill that draws a map of how the business runs. They share a name and a team. They do not share data.

Does it invent numbers?

No. If you did not supply an amount, it does not appear. The skill never calls QuickBooks, Stripe, Shopify, an ERP, or a bank.

What do I get back?

One self-contained HTML file. Zero dependencies, no server, no runtime. Open it in any browser, forward it, or export PNG, JPEG, WebP, SVG, or WebM.

Which agents does it support?

Cursor, Claude Code, Codex CLI, and OpenCode. Raven is not a switcher target; for a manual ZIP install, extract mosofin.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/mosofin. ZIP 手动安装：将 mosofin.zip 解压到 ~/.raven/workspace/skills，解压后会得到 ~/.raven/workspace/skills/mosofin.
