How it works

Four steps from add to a diagram you can forward.

Step 1

Add the skill

Install once for Cursor, Codex, Claude Code, or OpenCode. Raven stays a manual ZIP install.

Step 2

Describe the business

A short interview: what the business does, which entities are in scope, and which system owns each domain.

Step 3

Ask one question

Mosofin picks the diagram type, checks it, and hands back one HTML file you can refine in chat.

Step 4

Share the map

Forward the HTML, export a share card, or walk a guided view. Every gallery card is that same file.
