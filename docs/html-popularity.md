# How this HTML becomes popular

Short loop for the three-statements (and sibling) artifacts: one file people actually forward.

## Shareability

- **One file** — open in any browser; no login, no app install.
- **Dark / light** — `?theme=light|dark` or toolbar `T`.
- **Present / embed** — `?present=1` for live stage; `?embed=1` for iframe/proof cards.
- **Health** — `?health=1` when the author shipped `meta.health` (articulation maps).

## Placement

- Gallery + README **for CFOs** entry next to three-statements / money map.
- SEO-friendly docs pages (`three-statements.md`, this note, CFO playbook) with stable sample URLs under `docs/samples/`.
- Social OG on the public sample page so a LinkedIn share shows the map, not a blank card.

## Loop

1. Client gets the HTML (meeting handoff or gallery).
2. Asks for **their** books / brief.
3. Skill install or finance/business brief → new artifact with their joints.

## Distribution

- LinkedIn posts aimed at **fractional CFOs** and controllers (“replace the board slide”).
- Bookkeeper / CAS communities: month-end walkthrough clip + `?present=1` link.
- Hook: same file for the call and the leave-behind — no PPT export step.

## Product wedges

- Present / Health URL params and toolbar toggles on articulation maps.
- Reach / Share card (1200×630) from Export.
- Sibling deep links to Ledger City / money map for the same period.

## Metrics (conceptual)

Watch opens, Present-mode entries (`?present=1` / `F`), Health toggles, Share-card exports, and “send me your books” replies — not vanity pageviews alone.
