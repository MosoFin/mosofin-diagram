Step 1

Add the skill

Choose Cursor, Codex, Claude Code, or OpenCode. The switcher gives each one the same checked Skill. Raven stays a manual ZIP install.

Choose your coding agentCodex · same Skill

Global install
npx -y skills add MosoFin/mosofin-diagram --skill mosofin --agent codex --global --copy --yes
This repository only
npx -y skills add MosoFin/mosofin-diagram --skill mosofin --agent codex --copy --yes

Raven is supported through a manual ZIP installation, not a generated agent-switcher command. Extract mosofin.zip into ~/.raven/workspace/skills, which yields ~/.raven/workspace/skills/mosofin.

Step 2

Describe the business

A short interview: what the business does, which entities are in scope, and which system owns each domain. Then pick the question shape closest to what you need to see.

Choose the question shapeFive diagram types

The Start link carries only your agent, language, diagram type, and a coarse source label. Journey events stay in this browser session and are never sent by Mosofin. No repository path, title, node, relationship, or source JSON is recorded.
